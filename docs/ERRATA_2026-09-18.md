```sh

python scripts/verify_frozen_representations.py --receipt docs/representation-receipts/asset1-2026-09-18.json
```

Exit codes are 0 for all registered artifacts verified, 1 for a failed
checksum/contract check, and 2 for incomplete coverage due to absent
artifacts. Thus the public checkout is expected to return 2 for the
Asset-1 receipt until its two original feature matrices are provided.
The script reports whether a verified file is byte-identical to the
historical checksum or is the explicitly recorded alternate representation.
It recomputes both exact LF and reconstructed CRLF digests, requires
the historical checksum to match one of them, and requires identity
entries to match the historical bytes exactly. It rejects changed values,
unregistered JSON formatting, mixed line endings, inconsistent receipts,
altered checksum entries, and paths outside the repository.

The original XR-001 resume guard is intentionally unchanged. It compares
raw bytes, so the LF checkout remains unsuitable for resuming against the
historical CRLF task checksum without an explicitly reconstructed historical
task file. This receipt authorizes no resume or inference job. Changing the
runner's acceptance policy is a separate custodial decision; this correction
provides portable evidence verification without that policy change.
