# A7b — D1 replication on L1-taxonomy adapters, exploratory, n = 60

*Written 2026-09-06, before the analysis was run. Implements the Director's
Item 6 ruling of 2026-09-06 ("A7b, RUN IT bounded"), which authorized one
paragraph with three pins.*

The 60 completed L1 adapters used here are a zero-GPU held-out replication of
D1 on the same base model, and there is no reason to wait for 240 — but this
note must state what n = 60 can and cannot establish, because it cannot
establish what the ladder's confirmatory endpoint asks. At n = 60, K = 6,
balanced 10 per class, a perfect LOO gives a Jeffreys 95% interval of
**[0.959, 1.000]**, so the 0.99 ceiling is inside the interval and **A7b cannot
distinguish "at ceiling" from "one error below it"**; one error at n = 60 is
0.983, already under the ceiling definition (≤ 2 errors at N = 240). What A7b
*can* establish is the **direction and rough size of the raw-vs-canonical gap**
on adapters trained under the L1 taxonomy rather than the Asset-1 taxonomy: if
canonical is near 1.0 and raw is near chance on held-out adapters that share
nothing with the Asset-1 bank but the base model, D1's central finding
replicates out of sample. If the direction of the gap at n = 60 disagrees with
D1, that is a finding the ladder needs before L1 analysis, not after. The 60
adapters are named by run index below so that, when 240 are complete, the same
analysis can be re-run and the two compared.
